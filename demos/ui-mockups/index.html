BLOOM run-screen concepts

🧪VISUAL MOCKUPS ONLYNothing here runs the game. The map, regions, Biomass, coverage, trait effects, colony growth and specimen drawings are all scripted placeholders. Prices, effects and art are not proposals. Colours and fonts are placeholders too. Concepts 1–10 use emoji placeholder icons; Concepts 11–14 use a simple inline SVG placeholder icon set, which is the direction for the final UI (real icons, never emoji).

A change of direction, not another workbench refinement. The owner chose a new architecture: a stable full-map Planet View as home that hands off into dedicated, paused strategy rooms for Region Inspect, Adapt, Spread and Terraform. Every room keeps a smaller interactive map, and Adapt / Spread / Terraform get a visual evolution tree instead of card grids. Four versions of that one architecture are here to compare.

What all four share (so the comparison is fair)

✓ Common rules

  • Planet View is home. One large map, mounted once, never resized by exploring. Compact access to Regions, Map View, Adapt, Spread, Terraform and Pause / speed.
  • Entering a room auto-pauses. A PAUSED · strategy mode pill, a striped top edge and a Resume play button say so. Planet (or Escape) goes back and restores the clock as it was.
  • Every room has a mini-map you can click, hover to peek, re-target “Considering for”, and see previews on. Rooms link to each other, so you compare without close / reopen cycles.
  • Adapt and Spread change the organism (specimen layers glow). Terraform changes the environment only (sky / ground change, plant dims and is labelled unchanged).
  • No emoji. One inline SVG placeholder icon set across tools, categories, nodes and status chips.

✕ Not in this round

  • No production UI logic: fake data, scripted purchases, fake clock.
  • Later-tier tree nodes are placeholders (dashed, lock badge). They shape the trees and unlock visually when their parent is bought, but cannot be purchased. The 13 purchasable items are the same fake items as every earlier concept.
  • Costs, names, effects, art, colours and the icon drawings are not proposals.
  • The production UI is not locked by this round.
