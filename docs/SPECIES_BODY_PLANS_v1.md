**Status: ACCEPTED (PMO, 2026-10-10).** Concepts accepted: **Cinder Rosette** (dry / heat), **Woolly Candle** (cold), **Reed Spire**
(wet / flood) beside Organic Hybrid; the other concepts in §3 remain historical design alternatives only. BLOOM-035B implements the

## 1. The problem

Today a new art pack can only **re-skin Organic Hybrid's anatomy**:

| Fixed for every pack today | Where |
|---|---|
| one body plan (`art/plant/body-plan.json`, `bloom-plant-body-plan@2`): crown (42, 68), four stem layouts open / dense / compact / cushion, leaf sockets along one stem | `plant-compositor.js:91` reads the single global `A.bodyPlan` |
| one component registry: **34 components** (`art/plant/contract.json`) | `build-plant-art.mjs:189-192` demands every pack cover every component × angle × side |
| **117 sockets** (open 27 · dense 27 · compact 28 · cushion 29 · shared 6) | generated by `sockets()` (`plant-compositor.js:43-65`), also used by the build's clip proof |
| one trait → component grammar | `plant-components.js:27-56` names Organic Hybrid components directly |
| one pack in production | `plant-specimen.js:40` `const PACK = "organic-hybrid"` |
| the local-colony layer's sprout spots, lateral-root rule, seed bank | `plant-specimen.js:85-104` |
| stress tint | `plant-compositor.js:162`, `plant-specimen.js:47` |

Generic already: `plant-visual-model.js` (traits → normalized axes — the traits are the same for every species), `plant-fx.js` (pixel-diff
effects), the compositor's sprite placement / treatments / draw order, the build's PNG / palette / anchor validation, the specimen's
presentation layer (ghost, unviable, highlight).

Three genuinely different species need different stem geometry, leaf arrangement, root visibility, reproductive organs and a different
number of attachment points. That is a **body-plan** concern, one level above packs.

## 2. Architecture

```
species (content/species.js: art.bodyPlan, art.pack)
  → BODY PLAN       art/plant/body-plans/<plan>.json      canvas, ground line, crown, AXES (stems / rosette / sprite body), sockets,
                                                          architecture states, roots, local-colony layer
  → PLAN CONTRACT   art/plant/contracts/<plan>.json       this plan's component registry (ids, families, attach kinds, layers, angles,
                                                          trait + tier, maxSize, points, masks); shared materials / treatments by reference
  → PLAN GRAMMAR    resources/plant-visual/grammars/<plan>.js   select(model) → selection   (the ONLY trait → look rules for this plan)
  → ART PACK        art/plant/packs/<pack>/atlas.{png,json}      declares `bodyPlan: "<plan>@<n>"`; covers that plan's contract exactly
  → COMPOSITOR      plant-compositor.js render(selection, packId) — reads the plan through the pack; draws sprites at sockets
  → the canonical logical canvas (per plan; 84 × 98 for every plan in v1)
```

`plant-visual-model.js` stays **shared**: every species can buy every trait, so the normalized axes (`architecture.compact`,
`leaf.water`, `leaf.heat`, `roots.storage / aerial`, `surface.frost / wax / salt / pigment`, `repro.seedHead / flower / pods`) are the
species-independent vocabulary. Each plan's grammar decides what those axes look like on *its* body.

### 2.1 Body-plan manifest (`bloom-plant-body-plan@3`)

```jsonc
{
  "format": "bloom-plant-body-plan@3",
  "id": "rosette", "version": 1,
  "canvas": { "w": 84, "h": 98 },
  "ground": { "y": 68, "kind": "soil" },          // kind: soil | waterlogged (draws a shallow water band above the soil in the box)
  "crown": [42, 68],
  "contract": "rosette",                          // art/plant/contracts/rosette.json
  "grammar": "rosette",                           // resources/plant-visual/grammars/rosette.js
  "angles": ["flat", "low", "mid", "high"],       // this plan's authored angle steps (OH: low / mid / high)
  "architectures": {                              // states selected by model.architecture.compact (0–3) via the grammar
    "open": {
      "axes": [                                   // ONE OR MORE axes; each is a stem, a rosette or a sprite body
        { "id": "main", "kind": "rosette", "at": [0, 0],
          "sockets": {
            "leaf":   [{ "a": -150, "r": 2, "angle": "flat" }, { "a": 150, "r": 2, "angle": "flat" }, …],   // radial: angle a°, radius r
            "apex":   { "dy": -3 },                                                                          // the inflorescence base
            "axil":   []
          } },
        { "id": "spike", "kind": "stem", "at": [0, -3], "height": 0, "grows": "repro.flower",                // drawn only when the grammar asks
          "width": [2, 1], "bend": [0, 0, 1, 0], "sockets": { "flower": [{ "t": 1 }], "seedHead": [{ "t": 1 }, { "t": 0.7, "side": 1 }] } }
      ]
    },
    "dense": { … }, "compact": { … }, "cushion": { … }
  },
  "roots": { "visible": "cutaway", "depth": [10, 14, 18, 22], "width": [[3, 1], …], "wiggle": [ … ], "laterals": [ … ],
             "sockets": { "storage": { "dy": 6 }, "aerial": [ … ], "stilt": [] } },
  "local": { "sprouts": [-30, 31, -22, 24, -36, 37, -15, 17], "laterals": "primary", "seedBank": { "y": [3, 12] } }
}
```

Axis kinds (the only skeleton generalization):

| Kind | Draws | Sockets | Covers |
|---|---|---|---|
| `stem` | today's procedural stem (height, width taper, bend profile) | along `t` (leaves, nodes, axils, collars, branches, apex) | Organic Hybrid (one axis), a reed clump (several axes), an inflorescence spike |
| `rosette` | nothing (or a short procedural caudex) | radial leaf sockets around the crown (`a`, `r`, angle variant), an apex | a ground rosette, a giant rosette's crown (on top of a sprite body) |
| `sprite` | an **authored body sprite** by tier (e.g. `body.column.<tier>`) | points declared **by the sprite** (like leaf tip / margin points today), used as sockets | barrel / column bodies, woolly trunks, pads |

`kind: "stem"` with one axis reproduces body-plan@2 exactly. Nothing else is generic: no bones, no skinning, no rotation, no
animation rig. Every pixel is still an authored sprite or the existing procedural connective tissue.

### 2.2 Plan contract

Per plan: the component registry in today's contract format (`category`, `family`, `attach`, `layer`, `orientation`, `mirror`, `angles`,
`trait`, `tier`, `maxSize`, `points`, `masks`). Materials and treatments are **shared** by reference (`"materials": "@shared"`): every
pack still uses the 18-material ramp structure, so treatments (pigment, wax, toothed) and the stress shift work unchanged. A plan may add
attach kinds (`radialLeaf`, `bodyPoint`, `rhizome`, `waterline`) and families (`spine`, `wool`, `culm`, `umbel`, `pad`).

Rules carried over per plan: every pack of a plan covers every component × angle × side of that plan's contract; binary alpha; exact
palette colours; anchor conventions; the static clip proof of every socket × every legal model inside the canvas with a 1-px margin.

### 2.3 Plan grammar

A small pure module per plan, `BLOOM.plantVisual.grammars[planId] = { select(model) → selection }`, same output shape as today's
`select()` (layout → `architecture`, leaf component + angle step, leaf points, collars / wool, roots, apex / flower / heads / drift / pods,
treatments, stress, `components`, `key`). Organic Hybrid's grammar **is** today's `plant-components.js` (moved, not edited).

Why code and not a declarative rule table: the Organic Hybrid selector already has real rules that a table would have to grow a
language for (salt crystal on tips moves frost hair to other margins; heat T3 swaps the leaf structure; a seed head displaces the flower
to its branch). Each plan's grammar is ~40–60 lines, pure and fully covered by enumeration (every legal model → a selection that names
only components in the plan's contract and sockets in the plan) — the same N2 / N8 / N9 style proofs the pipeline check already runs.

### 2.4 Required vocabulary per plan (so Adapt / Spread stay meaningful on every species)

Every plan must give a visible, distinct answer for each axis, because the rooms map categories to parts
(`decision-rooms.js:111-112` `CAT_PART`):

| Axis (model) | Room part (CAT_PART) | Must show on every plan |
|---|---|---|
| `architecture.compact` 0–3 (Cold) | Temperature → "Stem" | a progressively more compact / insulated body |
| `leaf.water` dry 1–3 / wet 1–3 | Water → "Leaf shape" | a dry and a wet structural line, three tiers each |
| `leaf.heat` 1–3, `surface.wax` | Temperature | lifted angle + wax / heat variant |
| `surface.frost` 1–3 | Temperature | hairs / wool |
| `surface.salt` | Soil → "Roots" (+ leaf glands) | glands / crystals |
| `surface.pigment` (Radiation) | Hazard → "Leaf pigment" | pigment treatment |
| `roots.storage` / `roots.aerial` | Soil → "Roots" | storage organ / breathing roots |
| `repro.flower` (Early Maturity) | Growth → "Flowers" | an open flower |
| `repro.seedHead` 1–2 (Seed Output) | Seeds → "Seed head" | dispersal heads (+ drifting seeds at 2) |
| `repro.pods` (Waterborne Seeds) | Reach → "Pods" | buoyant fruit |
| condition strained / ghost / unviable | — | the shared treatments |

A plan may rename the part for its body ("Rosette" instead of "Stem", "Pads" instead of "Leaf shape") through an optional
`partLabels` map in the plan; the categories and mechanics never change.

A **specialist's innate strength is drawn in its base body, not as a purchased tier.** A dry specialist is already succulent at tier 0;
buying Drought deepens what it already has (more storage, thicker wax, a deeper tuber). Buying the *opposite* adaptation is drawn too
(a dry specialist buying Flood grows adventitious breathing roots and softer leaves), so every legal genome still has a picture.

### 2.5 Organic Hybrid stays valid without redrawing

- `body-plan.json` (@2) is converted to `body-plans/oh-stem.json` (@3): one `stem` axis per layout with the identical numbers; the
  contract moves to `contracts/oh-stem.json` unchanged; `plant-components.js` becomes `grammars/oh-stem.js` unchanged; the
  `organic-hybrid` and three proof packs declare `bodyPlan: "oh-stem@1"`.
- Proof of identity: for every legal Organic Hybrid model (the pipeline check's full enumeration), `render(select(model), pack)` before
  and after are byte-identical (rgba + placements + signatures); the 117 sockets and the 17 782-placement static clip proof are identical;
  `tools/golden` / intake checks unchanged; `PMO_FINAL_ACCEPTANCE.json` and the approved delivery ZIPs untouched.

### 2.6 Specimen and pipeline consumers

- `BLOOM.plantSpecimen.mount(host, { species })` — the pack and plan come from `species.art`; `data-pack` / `data-plan` attributes
  carry them; `PACK` constant removed. The local-colony layer reads `plan.local` (sprout spots, lateral-root source, seed-bank band).
- The stress tint and the environment backdrop move to the pack (`render.stressTint`, `environment`), defaulting to today's values.
- The build (`build-plant-art.mjs`) groups packs by plan: per plan a socket table, a clip proof and a coverage check; the generated
  atlas gains `bodyPlans` and `contracts` maps (the manifest's `sockets` becomes per plan).
- The intake tool is generalized: `tools/intake-plant-art.mjs --pack <id>` reads the pack's `PMO_FINAL_ACCEPTANCE.json` and its own
  delivery map instead of Organic Hybrid's hard-coded 55-sprite list (`intake-organic-hybrid-art.mjs:39-50`).
- `FINAL_PACKS` (`plant-sprite-pipeline-check.js:32`) becomes per plan.

### 2.7 What it deliberately does not do

No skeletal animation, no per-frame rigs, no rotation, no free-form deformation, no runtime procedural leaves. No per-species canvas
size in v1 (all 84 × 98 — the rooms, report and selection screen keep one specimen box). No shared "universal anatomy" that every species
must fit. The narrowest change that supports four visually and biologically distinct plants: **multi-axis skeleton + three axis kinds +
per-plan contract and grammar**.

## 3. Species concepts

Working names only. Each concept's physiology is the study's role physiology (SPECIES_SYSTEM §3.4) — the concepts differ in body, not
in numbers. Workload is in **authored drawings** (sprites + masks) for a complete pack, against Organic Hybrid's 55 sprites + 6 masks
(92 runtime sprites after mirrors).

### 3.1 Role B — dry / heat specialist

**B1 · Cinder Rosette** *(recommended)*

- **Silhouette:** a low, wide star of thick, upward-curving leaves pressed to the ground; when it flowers, one tall, narrow spike far
  above the rosette — a strong "low mass + one vertical line" read at 84 × 98, nothing like Organic Hybrid's leafy upright stem.
- **Anatomy:** ground rosette (`rosette` axis), thick fleshy leaves with toothed margins and a pale waxy bloom, a short caudex, a
  shallow, wide root fan; reproduction on a stem axis that only grows for Early Maturity / Seed Output.
- **Inspiration (not copied):** agave and aloe rosettes, Haworthia windows, Welwitschia's ground-hugging habit.
- **Physiology:** heat + dry-ground strengths; cold and wet weaknesses.
- **Adapt stays useful:** Cold → the rosette closes into a tighter, hair-fringed ball (architecture); Drought → fatter leaves, a
  translucent "window" tip, a deeper caudex; Flood → softer, longer, channelled leaves and adventitious breathing roots at the crown;
  Heat → more wax, steeper leaf angle; Salt → crystals in the leaf channels; Radiation → the pigment treatment.
- **Spread stays useful:** Seed Output → capsules along the spike, drifting winged seeds; Early Maturity → the spike blooms early;
  Waterborne Seeds → corky, buoyant capsules.
- **Body plan:** `rosette` axis + an optional `stem` axis (spike); radial leaf sockets (8–10); angles flat / low / mid / high.
- **Workload:** ~58 drawings (7 leaf structures × 4 angles = 28; heat variants 7 × 2 = 14; caudex / storage 2; breathing roots 3; frost
  fringe 3; salt 2; spike bud / flower / capsule small / large / drift / pod 6) — about Organic Hybrid's size.

**B2 · Lantern Barrel**

- **Silhouette:** an upright ribbed barrel with a crown of flowers; no leaves.
- **Anatomy:** `sprite` body by tier (ribs, areoles as body points), spines instead of leaves, a fibrous taproot.
- **Inspiration:** barrel cacti, columnar euphorbias (convergent, not copied).
- **Physiology:** as B. **Adapt:** Drought → more ribs / pleats (stores water); Flood → body softens, roots surface; Cold → wool on the
  crown; Heat → denser spines (shade).
- **Spread:** crown flowers, ribbed fruit, buoyant seed pods.
- **Body plan:** a `sprite` body axis with sprite-declared points; Water → "Leaf shape" becomes "Ribs" (partLabels).
- **Workload:** ~50 drawings, but each body sprite is large (≈ 30 × 40) and must be redrawn per Water tier × heat variant —
  the heaviest per-drawing cost. Risk: the iconic cactus read is very familiar.

**B3 · Ember Brush**

- **Silhouette:** a loose fan of thin wiry wands, tiny leaves, resin-tipped.
- **Anatomy:** 4–6 `stem` axes from one crown, minute leaf sprites along each.
- **Inspiration:** creosote bush, ocotillo.
- **Physiology:** as B. **Adapt:** Drought → leaves drop to scale-like, wands thicken; Flood → wands leaf out fully.
- **Body plan:** multi-stem; many small sockets (≈ 40).
- **Workload:** ~45 small drawings; reads weakly at small scale (thin lines); close to Organic Hybrid's "stem with leaves" language.

### 3.2 Role C — cold specialist (+ radiation)

**C1 · Woolly Candle** *(recommended)*

- **Silhouette:** a stout, upright woolly trunk wearing a skirt of dead leaves, topped by a tight rosette of silver-haired leaves; a tall
  candle-like flower column when it flowers — tall, vertical and soft-edged, the opposite of the dry rosette.
- **Anatomy:** `sprite` trunk body (wool + marcescent skirt by tier) + a `rosette` axis on top; reproduction as a dense column.
- **Inspiration:** Andean frailejón (*Espeletia*), East-African giant groundsels and lobelias — giant rosettes whose dead-leaf skirts and
  wool insulate the stem in alpine cold and high UV.
- **Physiology:** cold strength; heat weakness; radiation as a latent strength (dark-red pigment already at tier 0).
- **Adapt:** Cold → thicker skirt, crown leaves fold into a night-closed bud (architecture); Heat → skirt sheds, leaves open and pale;
  Drought → leaves narrow and silver; Flood → stilt-like trunk base; Salt → glands at the leaf bases; Radiation → deeper pigment.
- **Spread:** Seed Output → plumed seeds along the column; Early Maturity → the column opens early; Waterborne Seeds → floating plumed
  achenes.
- **Body plan:** `sprite` trunk (points: crown, skirt nodes) + `rosette` crown + `stem` inflorescence; ≈ 30 sockets.
- **Workload:** ~56 drawings (trunk tiers 4, rosette leaf structures 7 × 3 angles = 21, heat variants 14, wool / skirt overlays 4,
  roots 4, repro 6, salt 2, masks 3).

**C2 · Frost Cushion**

- **Silhouette:** a low, tight dome of hundreds of tiny shoots, starred with small flowers.
- **Inspiration:** cushion plants (*Silene acaulis*, *Azorella*).
- **Risk:** Organic Hybrid's own Cold T3 layout is already named "cushion" and is a compact low rosette — a cold specialist that looks like
  an evolved Organic Hybrid undermines "genuinely different species". Retained as an alternate only.
- **Workload:** ~40 drawings (dome sprite tiers + flower scatter); simplest, least distinct.

**C3 · Dark Fan**

- **Silhouette:** overlapping, nearly black, cupped lobes fanning from the ground like satellite dishes.
- **Anatomy:** `rosette` of lobes with radial ribs; no stem; spore-like dispersal cups.
- **Inspiration:** radiation-tolerant melanized organisms, liverworts, rock-tripe lichens (an alien twist: the pigment harvests radiation).
- **Physiology:** suits the radiation half of the role best; reads most "alien".
- **Workload:** ~48 drawings. Risk: the dark palette fights the specimen backdrop and the stress / unviable treatments; Hazard → pigment
  is already its base look, so Radiation Shielding would show weakly.

### 3.3 Role D — wet / flood specialist (+ salt)

**D1 · Reed Spire** *(recommended)*

- **Silhouette:** a clump of tall, thin, upright culms each ending in a starburst umbel — a vertical fountain, the tallest silhouette of
  the four, with a visible horizontal rhizome in the soil cutaway.
- **Anatomy:** 3–5 `stem` axes (culms) from a rhizome; leaves are basal sheaths; umbels at the apices; ground `waterlogged`.
- **Inspiration:** papyrus and sedges (umbels), reeds (*Phragmites*) and rice (aerenchyma), mangrove salt glands (for the coastal-salt
  strength).
- **Adapt:** Flood → more culms, aerenchyma bands, a deeper rhizome; Drought → culms shorten, sheaths harden, a storage rhizome node;
  Cold → culms bunch (architecture), frost on the umbels; Heat → umbels lift / open; Salt → crystals on the sheaths; Radiation → pigment.
- **Spread:** Seed Output → umbels swell to seed heads, drifting seeds; Early Maturity → flowering umbels; Waterborne Seeds → floating
  seed bundles (its natural strength in look as well as numbers).
- **Body plan:** multi-`stem` (culm count by architecture state), a `rhizome` root kind; ≈ 35 sockets.
- **Workload:** ~50 drawings (umbel structures × tiers 14, sheaths × water tiers 12, heat variants 8, rhizome / storage 3, breathing
  roots 3, frost 3, salt 2, repro 5).

**D2 · Lily Raft**

- **Silhouette:** broad round pads on a water line, one emergent flower — instantly readable as "wet".
- **Anatomy:** `rosette` of floating pads at `ground.kind: "waterlogged"`, long petioles below the line.
- **Inspiration:** water lilies, lotus.
- **Risk:** the game's land is never open water — a floating plant growing on dry-land regions reads wrong when the specialist
  colonizes ordinary or dry ground. The specimen box would need a water layer always. Retained as an alternate.
- **Workload:** ~44 drawings.

**D3 · Prop Mangrove**

- **Silhouette:** a small tree on arching prop roots, leathery leaves, hanging propagules.
- **Risk:** Organic Hybrid's Flood T3 already grows stilt and breathing roots with salt glands — the same vocabulary. Retained as an
  alternate only if the PMO accepts that overlap.
- **Workload:** ~52 drawings.

### 3.4 Recommendation

| Role | Recommended | Alternates kept for PMO review |
|---|---|---|
| A · generalist | **Organic Hybrid** (locked art, unchanged) | — |
| B · dry / heat | **B1 Cinder Rosette** | B2 Lantern Barrel, B3 Ember Brush |
| C · cold (+ radiation) | **C1 Woolly Candle** | C3 Dark Fan, C2 Frost Cushion |
| D · wet / flood (+ salt) | **D1 Reed Spire** | D2 Lily Raft, D3 Prop Mangrove |

Why this set: four clearly different silhouettes at 84 × 98 — an upright leafy stem (A), a low wide star with a spike (B1), a tall
woolly candle (C1), a vertical fountain of umbels (D1); four different body-plan shapes that exercise exactly the three axis kinds and
nothing more (A: stem · B1: rosette + spike stem · C1: sprite trunk + rosette + stem · D1: multi-stem + rhizome); none of them looks like
an evolved Organic Hybrid (the reason C2 and D3 are not recommended).

## 4. Art-production plan

1. **035B-5 (engineering):** body-plan@3 + per-plan contracts + grammars; Organic Hybrid migrated byte-identically; three **proof
   plans** (`rosette`, `candle`, `reed`) with **proof packs** (flat-shaded, "TEMPORARY PIPELINE PROOF — NOT FINAL ART", generated like
   today's proof packs) so every model renders and every check runs before any real art exists.
2. **Per species, an art brief** generated from the plan: the component list with `maxSize`, anchors, points, angle variants, the
   palette ramp structure, the environment colours, and the clip-proof budget per socket — the same artist hand-off Organic Hybrid used
   (BLOOM-032B2).
3. **Studio delivery → PMO acceptance JSON → intake** per pack (generalized intake tool), `check:plant-art`, the plan's pipeline checks,
   the integration checks with that species in the rooms / report / selection screen.
4. **Order:** the recommended B1 → C1 → D1 (rosette is the smallest skeleton change; candle adds the sprite body; reed adds multi-stem +
   rhizome), or in the PMO's priority order — packs are independent.
5. **Estimated authored drawings:** B1 ~58, C1 ~56, D1 ~50 ≈ **164 drawings** (+ masks), about three Organic Hybrid deliveries.

## 5. Risks

| Risk | Mitigation |
|---|---|
| OH render drift during migration | byte-identity over the full legal-model enumeration before any new plan lands |
| Grammar sprawl | one ~50-line pure module per plan, enumerated exhaustively by the pipeline check |
| A plan's maximal legal organism clips the canvas | the per-plan static clip proof (every socket × every legal model, 1-px margin) gates the build, as today |
| Species read as palette swaps | concept selection rule: different axis kind / silhouette per species; reviewed at proof-pack stage before art is commissioned |
| Room "part" words do not fit a body | `partLabels` per plan; categories and mechanics unchanged |
