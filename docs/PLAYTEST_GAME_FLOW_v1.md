# BLOOM — game flow playtest v1 (owner)

**What's new:** BLOOM now has a front door. Open **`index.html`** (the top of the Bloom folder) — no URLs to edit. Pick First Bloom, or a planet and then a scenario; the game prepares a fair world, you play, and afterwards you can replay that world or try another.

This is a plain temporary shell. Layout, look and icons are **not** final; we review design ideas and examples from similar games together in the next phase.

**Time needed:** about 10–15 minutes.

**Gate status:** ☐ not yet played.

## Task

1. Open `index.html` without editing the address.
2. **Start with First Bloom.** Play a little, then use **Menu → Home** (or finish it).
3. **Choose a New Planet**, pick any planet, then any scenario, read the briefing, press **Start**.
4. Finish or abandon that run.
5. Use one of: **Play this world again**, **Same planet, new world**, or **Change scenario**.
